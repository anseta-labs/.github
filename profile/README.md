# Anseta Labs

Open source tooling for the [Anseta](https://anseta.com) staking platform.

## Projects

| Repository | What it is |
|---|---|
| [**mcp**](https://github.com/anseta-labs/mcp) | An MCP server exposing the staking API to AI agents. Runs locally over stdio. |
| [**typescript-sdk**](https://github.com/anseta-labs/typescript-sdk) | Type-safe TypeScript client generated from the OpenAPI specification. |
| [**warden**](https://github.com/anseta-labs/warden) | Zero-trust validation library for integrators: check unsigned transactions before they are signed. |
